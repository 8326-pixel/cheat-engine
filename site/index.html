Open-source project

Cheat Engine

This page is a lightweight project portal for the 8326-pixel/cheat-engine repository. The original project is a native Windows development environment focused on game and application modding for personal use.

View GitHub repository Read the README

Native application

The repository is built for Windows rather than running as JavaScript in a browser.

Lazarus / Pascal

The README documents building the main project with Lazarus and Free Pascal.

Large codebase

The fork contains the main application source together with supporting native components.

Why it isn't deployed as a browser app

Web hosting platforms such as Vercel, Netlify and GitHub Pages serve web assets. They cannot execute a Windows desktop executable, DLLs or kernel-level components inside the browser. Because of that, deploying this repository directly as a website would produce a broken or misleading page.

Live web version: this page is documentation only. It does not emulate or run the native application in the browser.

Project structure

Cheat Engine/ — main application source DBKKernel/ — native kernel-related component DBVM UEFI/ — UEFI-related project files dbvm/ — low-level component sources lua/ — Lua-related sources .github/ — repository automation

Build information

The upstream README describes opening cheatengine.lpi in Lazarus and compiling the project on Windows. Additional native projects can be built separately depending on the features required.
